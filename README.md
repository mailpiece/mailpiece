# Mailpiece

This is the source code of [Mailpiece](https://mailpiece.dev/), a newsletter app you run yourself: you write posts, they appear on your newsletter's pages, and each one you send is mailed to your subscribers.


## Running your own Mailpiece instance

### Deploying with Docker

The quickest way to get going is to run our pre-built Docker image. You can find the details in our [Docker install guide](https://mailpiece.dev/docs/install.html).

### Deploying with Kamal

If you want to customize Mailpiece by changing its code, and deploy those changes to your server, then we recommend you deploy it with Kamal. You can find a complete walkthrough in our [Kamal install guide](https://mailpiece.dev/docs/kamal.html).


## The CLI and agents

The [Mailpiece CLI](https://github.com/mailpiece/mailpiece-cli) lets you work with your newsletter from a terminal, and gives your agents the same reach through MCP and an agent skill.
